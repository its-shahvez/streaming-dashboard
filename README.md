
# 🎬 StreamFlix - Streaming Dashboard Clone

A modern streaming service dashboard (Netflix Clone) built with Next.js 14, TypeScript, and Tailwind CSS.

## 🚀 Live Demo
**[Click here to view Live App](https://streaming-dashboard-pied.vercel.app/)**

## ✨ Features
- **Home Page:** Displays Trending, Top Rated, and Popular movies using TMDB API.
- **Hero Banner:** Randomly features a trending movie with a large backdrop.
- **Dynamic Details Page:** Click on any movie to view detailed info (Overview, Rating, Genres).
- **Responsive UI:** Fully responsive design inspired by Netflix (Dark Mode).
- **Server Side Rendering:** Utilizes Next.js App Router for fast performance.

## 🛠️ Tech Stack
- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **API:** The Movie Database (TMDB)
